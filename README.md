## Inspiration
- Food Waste Reduction
- Saving money

## What it does
Our project predicts how many days a food item will last based on its type, storage temperature, and humidity.

## How we built it
We used:
- Python + Pandas for data wrangling
- Gradio to create a clean, interactive web UI
- A dataset of 10,000+ food entries

## Challenges we ran into
- Ensuring case-insensitive food input
- Finding the sweet spot between model performance and user experience

## Accomplishments that we're proud of
- Working as a team and pulling it all together 
- Getting the program to run

## What we learned
- How to create an interactive UI with Gradio
- Teamwork and collaboration

## What's next for Food Expiration Forecaster for Smart Fridges​
- Integrate with real IoT smart fridges
- Use more data to make better predictions
- Give more food type options for the user
